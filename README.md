# PTSD SQL Project

## Overview

This repository contains a comprehensive SQL-based analysis project focused on Post-Traumatic Stress Disorder (PTSD) data. The project combines clinical research data with database management and analysis techniques to explore patterns, outcomes, and insights related to PTSD.

## Project Contents

- **PTSD Research Data**: Comprehensive dataset and documentation containing PTSD research findings, patient data, and clinical outcomes
- **SQL Analysis Scripts**: Database queries and analysis tools for extracting insights from PTSD-related data

## Purpose

This project aims to:
- Organize and structure PTSD research data in a relational database format
- Perform statistical analysis and data exploration using SQL
- Generate meaningful insights from clinical and research data
- Provide a foundation for further epidemiological and clinical research

## Getting Started

### Prerequisites
- SQL database management system (e.g., MySQL, PostgreSQL, SQL Server, SQLite)
- Basic understanding of SQL queries and database operations
- Familiarity with clinical data analysis

### Usage

1. **Clone the Repository**
   ```bash
   git clone https://github.com/hhuzief/PTSD_SQL_Project.git
   cd PTSD_SQL_Project
   ```

2. **Review Documentation**
   - Refer to `PTSD (1).pdf` for detailed research documentation and dataset specifications

3. **Execute Queries**
   - Use the provided SQL scripts to interact with the PTSD dataset
   - Adapt queries as needed for your specific analysis requirements

## Data Description

The project includes research documentation and data related to:
- PTSD diagnosis and classification
- Patient demographics and clinical profiles
- Treatment outcomes and follow-up data
- Risk factors and comorbidities
